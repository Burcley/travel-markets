# Travel Markets

Travel Markets is a modern student housing platform built to help students find trusted accommodation and help landlords connect with verified student tenants across Canada.

🌐 **Live Website:** https://travelmarkets.ca

---

## Features

- Student & landlord authentication
- Email and phone verification
- Identity verification system
- Property listing management
- Advanced property search & filters
- Saved searches & favorites
- Real-time messaging
- Viewing requests & scheduling
- Stripe subscriptions and billing
- Interactive maps
- Notifications
- Admin dashboard
- Mobile responsive UI

---

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- Supabase
- PostgreSQL
- Row Level Security (RLS)

### Services

- Stripe
- Twilio
- Resend
